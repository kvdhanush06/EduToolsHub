User-facing features (complete list)
===================================

Below is a concise list of every user-facing feature and subfeature available in the web application.

1) Account & Authentication
- Register: create an account (sign up)
- Login: authenticate and access your personal data
- Logout: securely sign out
- Profile: view/update personal profile information

2) Dashboard / Home
- Central landing page showing quick access to tools and recent items

3) Notes
- Notes list: view all notes
- Create note: add a new note (title, content, options)
- View note detail: see full content and metadata
- Edit note: update title, content and options
- Delete note: remove a note
- Note options: categorize/tag notes or set note-specific options
- Search/filter notes: locate notes by keyword/tag/options

4) Homework / Assignments
- Homework list: view assignments
- Create homework: add assignment with fields like title and due date
- Mark as finished: toggle completion status
- Edit homework: update assignment details
- Delete homework: remove assignments
- Filter/sort by due date or completion status

5) Todo List
- Todo list view: display short task items
- Add todo: create quick tasks
- Mark complete/incomplete: toggle task state
- Edit/delete todos
- Organize/filters: basic ordering or categorization

6) Books utility
- Search books by title/author/keyword
- View basic book metadata and summary

7) Conversion tool
- Unit/value conversions (instant conversion results)
- Copy/export conversion results

8) Dictionary lookup
- Word search for definitions
- View multiple senses, parts of speech and examples
- Pronunciation hints (if available)

9) Wiki / Reference
- Search wiki-style articles or short reference entries
- Read summaries or full articles

10) YouTube integration
- Search for videos by query
- Preview and play embedded videos inline

11) Navigation & Layout
- Global navigation for quick access to Notes, Homework, Todos, Utilities, and Account
- Mobile-friendly/responsive layout

12) Admin (site operators)
- Admin login access for site administrators (not available to regular end users without credentials)

13) Feedback & Validation
- Form validation and inline error messages
- Success confirmations after actions (e.g., saved, deleted)

14) Persistence
- Server-side persistent storage (data saved across sessions using the database)
